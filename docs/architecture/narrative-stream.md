# Separate local narrative stream (issue #4)

The existing `/api/matches/{name}/stream` football replay remains byte-identical and model-independent. The additional `/api/matches/{name}/narratives/stream?audience=analyst` SSE channel sends a `narrative_update` with stable `insight_id`, exact evidence IDs, controlled server-rendered text, audience and truthful source label `local_controlled`. `narrative_complete` terminates the finite local replay. This second channel cannot block the fast event path; UI keeps a separate EventSource that is cleaned up on scenario, mode or replay changes. Until a stable publication contract is approved and models can be tested, this prototype endpoint is excluded from the public OpenAPI contract and is not claimed as a production Foundry path.

`LocalAnalyst`/`LocalStoryteller` are deterministic providers which select allowed angles and presentation styles. They exercise the real `Orchestrator` and deterministic publication gate, but **are not AI models and do not invoke Foundry**. The UI explicitly labels such narratives `Local controlled narrative · No model inference`. There is no inference cost and no fabricated agent latency. A subsequent approved Foundry activation substitutes the agents behind the same port, adds bounded timeouts/staleness handling, per-role tracing and measured p50/p95 plus token and monetary cost.

A real high-press insight still arrives immediately on the original fast SSE stream. The separate narrative stream references that exact insight ID and underlying evidence; React only shows it when the corresponding tactical insight is visible. Invalid scenario and audience are rejected. A sustained-possession negative control emits no narratives. Tests cover payload/evidence matching, no unsupported narrative, source labeling and byte-identical fast replay.

**Limitations:** separate EventSource is acceptable for finite synthetic MVP but not yet a persisted multi-viewer narrative feed; publication ordering, reconnection and dynamic live feed persistence must be revisited before scaling. Narrative endpoint is deliberately a prototype pending the generated-contract integration and real inference tests.
